# 1. Форматирование строк. Format-string, f-string, %-string, raw-string, выравнивание строк.

_Форматирование вводится для создания строк, с изменяемыми переменными, во время работы программы_


*Существуют 4 типа форматирования:*

1. Format-string
``` python
print("Город: {}, улица: {}, дом: {}".format(sity, street, house))
```
Пустые {} заполяются по порядку

2. f-string
``` python
print(f"Город: {sity}, улица: {street}, дом: {house}")
```
Переменные вставляются в {} прямо в тексте

3. %-string
``` python
print("Город: %s, улица: %s, дом: %d, влажность воздуха: %.2f%%" % (city, street, house, percent))
```
Значения из кортежа подставляются в строку по порядку.
%s — значение в виде текста
%d — целое число
%.2f — число с двумя знаками после точки
%% — сам символ процента

4. raw-string
``` python
path = r"C:\new\test.txt"
print(path)
```

В сырой строке \n и \t сохраняются как обычные символы. Поэтому в этом пути \n не превращается в перенос строки, а \t — в табуляцию.

5. Выравниевание строк
``` python
word = "Python"

print(f"|{word:<10}|")  # |Python    |
print(f"|{word:>10}|")  # |    Python|
print(f"|{word:^10}|")  # |  Python  |
